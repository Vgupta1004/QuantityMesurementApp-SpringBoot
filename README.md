# Quantity Measurement App - Spring Boot

A Spring Boot application for measuring and converting various quantities.

## Overview

This application provides functionality to measure and manage different types of quantities with unit conversion capabilities.

## Features

- Quantity measurement and calculation
- Unit conversion support
- RESTful API endpoints
- Spring Boot framework

## Requirements

- Java 11 or higher
- Spring Boot 2.x or higher
- Maven

## Installation

1. Clone the repository
2. Navigate to the project directory
3. Run the following command:

```bash
mvn clean install
```

## Running the Application

To start the application, use:

```bash
mvn spring-boot:run
```

The application will start on the default port (usually 8080).

## API Endpoints

The application provides REST endpoints for quantity measurements and conversions.

## Building

To build the project:

```bash
mvn clean build
```

## Project Structure

- `/src/main/java` - Main application source code
- `/src/test` - Test files
- `/pom.xml` - Maven configuration file


This project is open source.
